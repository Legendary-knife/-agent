# 《徒儿你已无敌了》强降AI版｜视频制作规格

## 最终拆分结论

- **原剧本**：75集
- **成片规格**：9:16竖屏、每条约30秒
- **建议拆分**：**385条**
  - E001-E153：原第1-29集
  - E154-E286：原第30-54集
  - E287-E385：原第55-75集
- **总成片时长**：约192.5分钟
- **风格**：都市高武漫剧、国漫赛璐珞漫画质感、高手下山、神医爽剧、家族与师门悬疑

## 为什么拆成385条

用户要求台词可以保留，不要为了压时长删掉解释剧情的关键台词。原75集信息量大，包含杭城家族战、五位师姐、青冥殿、九眼天珠、陆家旧案、昆仑研究所、长生会、医学峰会、长生岛和神医门洗冤等多条线。如果仍按原先225条压缩，许多30秒视频会同时塞入多个场景，台词来不及说完，观众也难理解人物为什么行动。因此本版采用“一次冲突、一个反转、一个钩子”拆分，平均每个原集约5条。

## 字幕与姓名牌硬规则

1. **所有对白、必要OS/VO均生成中文字幕**。
2. 字幕位于画面底部安全区，白字黑描边；单行尽量不超过16个汉字，长句拆成两条。
3. **新人物第一次正面出场必须出现姓名牌**，格式：`姓名｜身份`，停留约1.5秒。
4. 人物电话/声音先出场时可用“声音首出”姓名牌，实体出现时再补正式姓名牌。
5. 台词以原剧为基础，不删除解释动机和因果的关键句；只修正重复、病句、称谓和明显逻辑冲突。
6. 每条30秒尽量保留4-8句关键对白；对白较密时使用快速切镜，不让一条字幕停留过久。

## 30秒节奏

- **0-4秒**：上集承接或强冲突开场
- **4-10秒**：交代人物目的和起因
- **10-18秒**：冲突升级，关键台词解释“为什么”
- **18-25秒**：主角出手、揭露或反杀
- **25-30秒**：结果与下一集钩子


## 已统一修正的重点逻辑

- 陆昭六岁获救、现年二十，叶红绡应为“养他十四年”，不是二十年。
- “许棠”是苏清瑶上山求医使用的化名；正式认出后统一称苏清瑶。
- 五位师姐排行、专长与称谓按首次出场姓名牌固定，避免群像混乱。
- 司徒晦后期同时出现两具身体时，统一称“司徒晦·旧身”和“司徒晦·原身复苏”。
- 陆母首次正式重逢标注“陆母婉宁”，后续统一称谓。
- 医学峰会的“摄像机”修正为伪装成摄像机的信号中继器。
- 叶红绡二十年前交出陆承岳的行为补充动机：她将“当场灭口”换成“留作血契试验”，救了命但也造成二十年囚禁，责任不被抹去。
- 苏清瑶被带走前保留生命贴片，解释后续定位来源。
- 长生岛火山危机提前通过火脉、磁雾和血阵压制机制铺垫。
- 神医门洗冤与婚礼之间增加“数周后”，避免案件刚结束次日就办婚礼。
