# 《封印失效前》即梦30秒生成包

本生成包把第一季30集拆成180个视频单元。每集6段，每段30秒，成片仍为每集约3分钟。

## 建议生成顺序

1. 先固定角色参考图，再生成第01集第01段。
2. 每段生成完成后，截取最后一帧，作为下一段的首帧参考图。
3. 同一集内不更换人物参考图、服装、发型、道具和画幅。
4. 跨集时先看该集文件顶部的“本集连续状态”，再沿用上一集最后一段的末帧。
5. 字幕必须使用分段文件中的原文和时间码，不自行改词。若即梦原生文字出现乱码，保留人物对白音轨，在剪辑环节按同一字幕轨覆盖。

## 统一成片规格

- 画幅：9:16竖屏。
- 单段时长：30秒。
- 风格：中国真人都市异能悬疑短剧，写实电影质感。
- 帧率观感：24fps，动作自然，不使用高速鬼畜剪辑。
- 色彩：现实线以冷青、灰白为主，修理铺保留暖黄，记忆与异能使用暗红、蓝白微光。
- 字幕：简体中文，白字黑描边，画面底部安全区居中，最多两行，不显示说话人姓名。
- 声音：普通话对白，环境声连续，音乐压低，不盖住台词。

## 文件说明

- `角色与统一参数.md`：角色外观、世界视觉和统一负面约束。
- `第01集.md` 至 `第30集.md`：逐段复制到即梦使用的提示词。
- `字幕轨.csv`：180段全部对白时间码。
- `生成清单.csv`：生成进度、首尾帧和连续性记录。

## 连贯性硬规则

- 人物受伤、衣服破损、淋雨程度、手中道具必须承接上一段。
- 上一段末帧的站位、视线方向和动作，直接作为下一段开场。
- 沈砚每次使用封印后，都要保留相应的虚弱、失神或记忆缺口。
- 许知微使用能力后，画面应短暂降为灰度，并保留到剧情明确恢复。
- 秦照野发动静默时，环境异能效果停止，他本人心跳同步停止，脸色迅速灰白。
- 除剧情明确要求外，画面中不生成可读招牌、界面文字和水印，字幕除外。
